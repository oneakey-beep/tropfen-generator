# Tropfen-Generator

Web-App, die die Bewegung in einem Tanzclip erkennt und Wassertropfen in Bewegungsrichtung abspritzen lässt. Export als PNG-Sequenz mit Alpha (ZIP) für After Effects.

- Clip laden oder per Drag & Drop
- Regler oder numerische Eingabe für Menge, Schwerkraft, Lebensdauer, Größe usw.
- Eigene Partikel-Bilder (PNG mit Transparenz)
- Alles läuft lokal im Browser
